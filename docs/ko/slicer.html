Duplicator 9 슬라이싱하기

열두 대의 프린터마다 하나씩, UltiMaker Cura와 OrcaSlicer용 프로파일입니다. 둘 다 무료이고 Windows, macOS, Linux에서 쓸 수 있습니다. 각 프로파일에는 그 프린터 펌웨어의 출력 크기, 가속도, 최고 베드 온도가 들어 있습니다.

이 사이트의 펌웨어, v2.0.9 이상에 맞춰 만들었습니다.

설치하기

OrcaSlicer: 파일 → 가져오기 → 설정 가져오기…를 고른 다음 .orca_printer 파일을 선택하세요. 프린터와 세 가지 품질(0.12, 0.20, 0.28 mm), 그리고 PLA, PETG, ABS 필라멘트가 프리셋에 나타납니다.

Cura: 도움말 → 설정 폴더 표시로 폴더를 연 뒤 Cura를 닫고, 파일의 압축을 그 폴더에 풀고, Cura를 다시 켠 다음 설정 → 프린터 → 프린터 추가… → 네트워크에 연결되지 않은 프린터 추가 → Wanhao → 자기 모델 순으로 고르세요. Cura에 기본으로 들어 있는 Wanhao Duplicator 9는 더 오래된 프로파일입니다: 300만 있고, 래프트와 서포트가 기본으로 켜져 있습니다.

첫 출력 전에: Z 오프셋, 그다음 프로빙

프로브는 베드보다 조금 위에서 반응하고, 펌웨어는 그 차이가 얼마인지 알아야 합니다. 그것이 Z 오프셋입니다. 너무 높으면 첫 레이어가 붙지 않고, 너무 낮으면 노즐이 베드를 긁습니다. 한 번만 맞추면 되며, 출력물이 붙느냐 마느냐를 결정하는 단 하나의 설정입니다.

아래 내용은 모두 슬라이서가 아니라 프린터의 메모리에 저장됩니다. 펌웨어를 업데이트해도 남아 있습니다(v2.0.3부터).

1. 먼저 가열하세요

뜨거운 노즐은 100분의 몇 mm 더 깁니다. 출력할 때처럼 가열하세요. 화면에서 온도 → 예열 → PLA(200 °C와 60 °C)를 누르고 2분쯤 기다립니다.

2. 축을 원점으로 보내세요

화면에서: 설정 → 이동 → 원점. USB로는: G28.

3. Z 오프셋을 맞추세요

가장 쉬운 방법, 출력하면서. 출력을 시작하고 첫 레이어가 그려지는 동안 화면에서 조정 → Z 오프셋으로 가세요. 선이 그려지는 동안 0.01 mm씩 내려서, 선이 납작해지고 옆 선과 틈 없이 맞닿을 때까지 맞춥니다. 너무 높으면 선이 둥글게 따로 놀고, 너무 낮으면 표면이 거칠어지면서 노즐이 파고드는 것이 보입니다. 값은 저절로 저장됩니다.

종이로, 출력하지 않고. 출력 온도로 데운 채 USB로:

M851 Z0     ; 지금 들어 있는 오프셋을 지웁니다
M500
G28         ; 반영되도록 다시 원점으로 보냅니다
M420 S0     ; 재는 동안 메시를 무시합니다
M211 S0     ; Z0 아래로 내려갈 수 있게 합니다. 소프트웨어 리밋이 노즐을 거기서 막습니다
G1 Z0 F300  ; 펌웨어가 0이라고 여기는 높이까지 노즐이 내려옵니다

노즐 밑으로 종이 한 장을 밀어 넣고, G91 다음 G1 Z-0.05 F60을 여러 번 써서 조금씩 내리다가, 종이가 겨우 끌리기 시작하면 멈추세요. M114로 값을 읽습니다. 음수이며, 예를 들면 −1.30입니다. 그다음:

G90
M851 Z-1.30 ; 여러분의 값
M500
M211 S1     ; 소프트웨어 리밋을 되돌립니다. 베드를 지켜 줍니다

4. 베드를 프로빙하세요

화면에서: 설정 → 레벨링 → 자동 → 프로브. 프린터가 25점을 재고 메시를 알아서 저장합니다(G29 다음 M500을 실행합니다). 몇 분 걸립니다. USB로는: G29 다음 M500.

우리 프로파일은 출력할 때마다 프로빙하지 않습니다. 원점 복귀 바로 뒤에 M420 S1로 저장된 메시를 다시 켤 뿐입니다. 그러니 프린터를 옮겼을 때, 출력면이나 노즐을 바꿨을 때, 또는 베드 한쪽은 첫 레이어가 잘 나오는데 다른 쪽은 그렇지 않을 때 다시 프로빙하세요.

5. 확인하세요

M503은 저장된 값을 보여 줍니다. M851 줄이 Z 오프셋이고, M420 S1은 메시가 켜져 있다는 뜻입니다. 화면에서는 자동 페이지에 측정한 25점이 보입니다.

테스트 출력

두 슬라이서를 비교하거나 설정을 확인할 때 아무것도 설치하지 않고 바로 쓸 수 있도록, D9 MK2 300용으로 이미 슬라이싱해 둔 3DBenchy입니다:

  • Cura: PLA · PETG · ABS
  • OrcaSlicer: PLA · PETG · ABS

각각 한 시간 반쯤 걸리고 필라멘트 4 m를 씁니다. 다른 모델이나 다른 크기라면 3DBenchy를 자기 프로파일로 직접 슬라이싱하세요.

무엇부터 시작할까: D9 MK2 300에서 PLA로 같은 Benchy를 뽑아 보니 OrcaSlicer는 1시간 14분, Cura는 1시간 22분이 걸렸고, 벽면은 OrcaSlicer 쪽이 조금 더 깔끔했습니다. 둘 다 좋지만 저희라면 OrcaSlicer로 시작하겠습니다. 더 파고들고 싶어지면 이 슬라이서의 캘리브레이션 도구(플로우, pressure advance, 온도 타워)가 도움이 됩니다.

D9는 개방형입니다: ABS는 적어도 바람이 들지 않는 방이 필요하고, 베드 온도는 자기 모델이 견디는 값까지 낮춰 두었습니다(MK3 500은 80 °C).

프로파일에 들어 있는 설정

  • 레이어 0.20 mm, 벽 3줄, 윗면 4겹과 바닥 3겹, 자이로이드 인필 15 %, 2줄 스커트, 서포트 없음.
  • 속도: 바깥쪽 벽 40 mm/s, 안쪽 60, 인필 70, 첫 레이어 20, 이동 150. Wanhao는 D9의 최고 출력 속도를 70 mm/s로 밝히고 있습니다.
  • 리트랙션 1.5 mm, 25 mm/s: D9는 모두 다이렉트 드라이브 MK10 압출기를 쓰고, 펌웨어가 압출기를 25 mm/s로 제한합니다.
  • 온도: PLA 210 °C 뒤 205, 베드 65 뒤 60. PETG 240 / 80 뒤 235 / 75. ABS 245 / 105 뒤 245 / 100.
  • 프라임 라인은 왼쪽 가장자리에서 15 mm 떨어진, 베드 클립을 비켜난 자리에 그려서 노즐이 깨끗한 상태로 모델에 도착합니다.
  • 끝나면 노즐이 올라가고 베드가 앞으로 나옵니다.
